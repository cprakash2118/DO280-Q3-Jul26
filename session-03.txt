************************* Discussion Start *******************************
- Defining and Applying Permissions with RBAC
- Authorization process 
  Rule  - Allowed actions for objects or groups of objects.
  Role  - Sets of rules. Users and groups can be associated with multiple roles.
  Binding - Assignment of users or groups to a role.
  
- Scope of RBAC.
  1-) Cluster Level 
  2-) Namespace/local level 

- Binding:-
  - ClusterRoleBindings 
  - RoleBindings

Role vs RoleBindings

Default Roles:-
1-# cluster-admin (same as root account w.r.t Linux) 
2-# cluster-reader 
3-# cluster-status 
4-# self-provisioner
5-# admin (w.r.t namespace)
6-# edit (w.r.t namespace - able to edit k8s/ocp resources like Deployment,Secret etc)
7-# view (w.r.t namespace - able to view k8s/ocp resources - Monitoring/logging solution)
 
************************* Discussion Ends *******************************
