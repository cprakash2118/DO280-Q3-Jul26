Point-3) Authentication & Authorization.
  3.1-# Authentication via OAuth.
        - IdPs (Identity Provider - htpasswd, LDAP, OIDC=RHSSO, PingIdentity etc).
  3.2-# Authentication via Client Certificate.
        - Client Certificate X509 for authentication.
		

  3.1-# Authentication via OAuth.
       What is OAuth ?
	   OAuth is an identity broker, On behalf of OpenShift OAuth sync with IdP (Identity Provider).

       What is IdP?
       Identity Provider like htpasswd (local), LDAP, Active Directory, RHSSO, AWS IAM, Google/Git Authenticator.
   
       As per DO280v418 -> Using htpasswd as IdP.
      
Lab-01-# 
Task-01
 - Create users using IdP=htpasswd
   UserName=user1-5/redhat ; secret-name=secret-sre ; IdP Name="IdP-htpasswd-sre-Team"
   UserName=user6-10/redhat ; secret-name=secret-devops ; IdP Name="IdP-htpasswd-devops-Team"
   UserName=user11-20/redhat ; secret-name=secret-myapp ; IdP Name="IdP-htpasswd-myapp-Team"   

Step-1# Create User's database. 
  $ htpasswd --help 
  $ htpasswd -c -B -b htpasswd-file user1 redhat
  $ htpasswd -B -b htpasswd-file user2 redhat
  $ htpasswd -B -b htpasswd-file user3 redhat
  $ htpasswd -B -b htpasswd-file user4 redhat
  $ htpasswd -B -b htpasswd-file user5 redhat  
  $ cat htpasswd-file
  
Step-2# Create secret (Place this information to OCP cluster).
  $ oc create secret generic secret-sre --from-file htpasswd=htpasswd-file -n openshift-config 
  $ oc get secret secret-sre -n openshift-config
  
Step-3# Update to OAuth service.
  $ oc get oauth cluster 
  $ oc get oauth cluster -o yaml > oauth.yaml
  $ vim oauth.yaml 
  https://docs.redhat.com/en/documentation/openshift_container_platform/4.18/html/authentication_and_authorization
  
  $ oc apply -f oauth.yaml 

Step-4# Verify the work 
  $ oc get pods -n openshift-authentication
  Oauth pods are getting restarted to refelect new updated changes.
  
  $ oc login -u userName -p password https://api.ocp4.example.com:6443
