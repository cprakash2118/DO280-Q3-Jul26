Task 03: Configure Role-Based Access Control
healthcare-admin-grp
└── cluster-admin access

healthcare-dev-grp in namespace ns-medicare-app
├── health-dev01–02 → admin
├── health-dev03–06 → edit
└── health-dev07    → view

healthcare-support-grp
├── view → ns-medicare-app
└── ns-medicare-monitoring:
    ├── health-support01–04 → edit
    └── health-support05–10 → view
	

Additional requirements:
1. Only healthcare-admin-grp can create namespaces.
2. Developers can deploy applications but cannot manage RBAC.
3. Support users can view application resources and logs.
4. Only selected support users can modify monitoring resources.
